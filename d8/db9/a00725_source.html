35 @details These macros use compound statements to create local scopes for the

37 respectively. This ensures that if x or y have side effects (such as being

39 @note The use of typeof allows the macro to work with any data type.

43 more robust way to determine the minimum and maximum values between two
44 expressions without risking unintended consequences from multiple
45 evaluations.
46 */
