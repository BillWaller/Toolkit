217/* @name UI Backend API
218 @ingroup ui_backend
219 @details The following functions define the API for implementing a backend for the terminal UI library. These functions cover the initialization and shutdown of the UI runtime, management of surfaces, drawing operations, input handling, and cursor control.
220 Each function is designed to be implemented by the backend according to the specifications provided in the function comments. By implementing these functions, you can create a functional backend that allows the terminal UI library to render and interact with users effectively.
221 Note: ui_init should return NULL on failure and set an appropriate error
222 message that can be retrieved by the caller. The error message should provide
223 details about the reason for the failure, such as issues with terminal
224 capabilities, resource allocation failures, or unsupported features. This
