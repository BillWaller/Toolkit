65/** @brief max macro evaluates two expressions, returning greatest result.
66 @details These macros use compound statements to create local scopes for the
67 temporary variables _x and _y, which store the values of x and y,
68 respectively. This ensures that if x or y have side effects (such as being
69 incremented), they will only be evaluated once when the macro is expanded.
70 The use of typeof allows the macro to work with any data type.
71 The line (void)(&_x == &_y) is a compile-time check to ensure that the
72 types of the arguments are compatible.
73 This implementation of the min and max macros provides a safer and
74 more robust way to determine the minimum and maximum values between two
75 expressions without risking unintended consequences from multiple
76 evaluations.
77 */

79 ({
80 __typeof__(a) _a = (a);
