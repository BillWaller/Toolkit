void external_receiver_command ( struct LF lf,
char * dir,
char * re,
char ** eargv )

Execute an external command with the output of lf_find as input.

Parameters
lfThe LF struct containing the options and flags for lf_find.
dirThe directory to search for files.
reThe regular expression to match file names against.
eargvThe argument vector for the external command to execute.

This function creates a child process to execute the external command specified by the user. It sets up a pipe to redirect the output of lf_find to the standard input of the external command. The parent process runs lf_find and writes its output to the pipe, while the child process reads from the pipe and executes the external command. After lf_find completes, the parent process waits for the child process to finish before exiting.
